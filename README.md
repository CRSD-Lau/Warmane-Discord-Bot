# Warmane Discord Bot

Slash commands:
- `/gs <name>` — GearScore (WotLK 3.3.5a). Slots from Armory grid; ilvl/quality from Cavern/Wowhead.
- `/guild` — Full roster with button pagination.
- `/profile <name>` — Armory profile screenshot with padding/border.

## Setup
1. Copy `.env.example` to `.env` and fill in values.
2. `npm install`
3. `node index.js` (or `pm2 start index.js --name warmane-bot`)
